# Sales & Profit Dashboard – Excel

## 📊 Project Overview
This project showcases an interactive **Sales & Profit Dashboard** built using **Microsoft Excel**. The dashboard provides a comprehensive view of business performance by analyzing sales, profit, customers, and trends across multiple dimensions.

It is designed to support **data-driven decision-making** through clear KPIs and intuitive visualizations.

---

## 🎯 Objectives
- Analyze overall sales and profit performance
- Identify profitable product categories and customers
- Understand yearly, monthly, and geographical sales trends
- Present insights in a professional and interactive dashboard format

---

## 🧩 Key Dashboard Components
- **Total Sales & Total Profit KPIs**
- **Profit by Year** (Category-wise comparison)
- **Sales by Category** distribution
- **Customer Count by Year**
- **Sales by State** analysis
- **Monthly Sales Trends**
- **Top 5 Customers by Profit**

---

## 🛠️ Tools & Techniques Used
- Microsoft Excel  
- Data Cleaning & Preparation  
- PivotTables & PivotCharts  
- Slicers for dynamic filtering (Category, Year, Month)  
- Conditional Formatting  
- Dashboard layout and visual design principles
